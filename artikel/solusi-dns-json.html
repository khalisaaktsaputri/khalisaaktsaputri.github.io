Resolving GitHub Pages DNS Issues & JSON Parsing Errors

10 Juni 2026

Hari ini gua mendokumentasikan masalah sinkronisasi antara domain DuckDNS dan hosting GitHub Pages. Kasus eror JSON kemarin terjadi karena sistem mencoba memuat data, tetapi jalurnya terputus akibat IP DuckDNS yang berubah otomatis kembali ke IP internet rumah.

Solusi yang berhasil diterapkan adalah mengunci IP server resmi GitHub Pages langsung di dasbor DuckDNS dan memastikan struktur file CNAME sudah bersih tanpa embel-embel protokol tautan.
